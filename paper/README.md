## 格式對照（依 TANET2026 論文格式說明）

- A4、上下左右邊界各 2.5 cm、雙欄、欄距 0.5 cm、單行間距
- 論文標題 16pt 粗體；作者資料與第一層標題 12pt 粗體；第二層標題 11pt 粗體
- 圖表說明 10pt 粗體；內文與參考文獻 10pt 標準體
- 中文標楷體、英文 Times New Roman；未插入頁碼
- 表格說明置於表格上方置中、圖說置於圖形下方置中
- 參考文獻依內文引用順序連續編號，內文以 [n] 引用

## 待補內容

文中以紅色粗體 `【…】` 標示者為待填欄位，主要集中在：

- 第 4.2 節研究對象人數、第 4.5 節統計軟體
- **第 5 節「研究結果」**（表 1–表 9 骨架已備妥，待填數值與文字說明）
- 第 6 節「討論」（已列撰寫脈絡）
- 摘要與第 7 節結論中之研究發現摘述
- 圖 1（系統架構圖）、圖 2（研究流程圖）請自計畫書插入

## 已知取捨

## 重新產生 docx

論文內容請改 `TANET2026_論文初稿.md`，再以 `build_docx.js` 重新產生 docx。

```bash
npm install docx
node build_docx.js
```
